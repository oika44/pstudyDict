P-Study 用 単語ファイル作成アプリ
================================

■ 必要なもの
  Node.js 18 以上 (https://nodejs.org/ の LTS 版でOK)
  ※ npm install は不要です。

■ 起動
  Windows   : start.bat をダブルクリック
  Mac/Linux : ターミナルで sh start.sh

  ブラウザで http://localhost:4321 が開きます。
  (開かない場合は手動でこのアドレスを開いてください)

■ 終了
  黒いウィンドウ (コンソール) を閉じる、または Ctrl+C

■ 使い方
  1. 英単語を 1 行に 1 語入力し「Weblio で検索して追加」
  2. 一覧で訳を必要に応じて編集
  3. 文字コード (Shift_JIS / UTF-8) を選んで「CSV ダウンロード」で保存
  4. P-Study System でその CSV をインポート (1 列目=問題, 2 列目=解答)

■ 注意
  - 訳は Weblio 英和辞書のページから取得しています。個人利用の範囲でお使いください。
  - ポート 4321 が使用中の場合は、環境変数 PORT で変更できます
    (例: set PORT=5000 の後に node server.mjs)。その場合はブラウザのアドレスも合わせてください。
